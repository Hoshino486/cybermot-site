跑图这件事，服务器给的东西永远不够用。

想练一段跳，得等回合结束；想看看后面几关长什么样，只能求人带你过；想标记「这里要踩点」，只能站那儿按语音喊。所以我自己写了一个插件，把这些都塞进去。

它叫 **ZePractice**，一个跑在 CounterStrikeSharp 上的 CS2 服务端插件。

## 它做了什么

一句话：**把「练图」和「带图」需要的东西，做成聊天框里能敲出来的命令。**

| 模块 | 内容 |
|---|---|
| 练习跑图 | 无敌、穿墙、存档、传送、重置、补给 |
| 人类指挥 | 五色标点、按住 R 画线、倒计时、指挥官高亮 |
| 换图投票 | 候选列表、严格 80% 的 RTV、服主直换 |
| 工坊资源 | 已装内容每 60 秒查更新，不打断当前回合 |
| 练习 Bot | 个人 Bot 陪练、传送编号、队伍选择 |
| 神器监听 | 取代原生 EntWatch，读真实规则显示持有者与冷却 |
| 地图标记 | 实体按钮绿鸡、落地枪青绿轮廓、发光字段网络同步 |
| 诊断 HUD | 实体数、模拟均值、TPS、内存、人数 |

## 练习模式

跑图服的核心是「一个人也能练」。这些命令只在练习模式生效：

```text
!ze_god        无敌
!ze_noclip     穿墙
!ze_save       存一个点
!ze_tp         回到存点
!ze_reset      清掉存点
!ze_respawn    原地复活
!ze_goto <玩家>  传送到某个人身边
!zerefill      补满弹药和道具
```

存档点是**按地图隔离**的，换图不会串；新回合开始会自动清理，不会出现「上个回合的位置还能用」这种事。多人 ZE 模式下这些命令会被撤销，避免影响正常局。

## 指挥

带图最麻烦的是沟通，所以做了三样东西：

1. **五色标点**：每人五种颜色，标点带倒计时；指挥官交接时共享同一套点，不是各标各的
2. **按住 R 画线**：直接在屏幕上画路线，每段保留 10 秒，由旧到新自动消退
3. **指挥官高亮与倒计时**：谁是指挥一眼看得出来

这些是给「带图的人」用的，不是给管理员用的 —— 任何人拿到指挥权都能用。

## 换图与工坊

原生的换图流程太重，我接管了：

- `!ze_maps` 拉候选列表，可以按 ID 筛选
- `rtv` **严格超过 80%** 才换图，不是简单多数
- 服主可以跳过投票直接换

工坊资源的处理是另一条线：已安装的内容**每 60 秒后台检查一次更新**，但不会强制换图、不会结束回合 —— 新内容等下次加载时生效。这样更新不会打断正在跑图的人。

## Bot 与诊断 HUD

一个人跑图时，有些机关需要另一个「人」配合，所以加了个人 Bot：可以选队伍、用编号传送。

诊断 HUD 是最近才加的（当前 1.7.x）：彩色实体数、网络索引实体数、模拟均值与峰值、TPS、内存、人数。它们默认对所有人显示，也能用 `!ze_diag off` 单独关掉。

写这个的起因很土 —— 卡的时候得知道是实体太多、还是 TPS 掉了、还是内存爆了，靠猜太慢了。

## 怎么装

依赖是官方那套：

| 组件 | 版本 |
|---|---|
| CounterStrikeSharp | 1.0.376（含 .NET 10 运行时） |
| Metamod:Source | 2.0.0-dev+1480 |
| CS2Fixes | 2.0 |
| StripperCS2 | v2.0.1（部分地图需要） |

编译只需要 .NET SDK 10：

```powershell
dotnet build ZePractice.csproj -c Release -p:CssApiDir="<CS2>\game\csgo\addons\counterstrikesharp\api"
```

然后把 `ZePractice.dll` 丢进 `plugins\ZePractice\`，首次启动会生成配置文件，把自己的 SteamID64 填进 `OwnerSteamIds`，重启，聊天框敲 `!zemenu`。

SteamID64 用 `!ze_whoami` 查。

## 几个踩过的坑

写这个插件的过程中，有几件事值得单独记一下：

**工坊地图不能冷启动。** 直接 `+host_workshop_map` 会停在 `Idle console`。必须先加载内置图（`de_dust2`），等地图 active、RCON 就绪，再通过 RCON 发命令。所以启动器是两段的。

**地图列表里的工坊 ID 是数字字段。** CS2Fixes 的 `maplist.jsonc` 里要用 `"workshop_id": 3817448617`，不是 `publishedfileid`，也不是随便一个相近的 ID。

**RCON 密码别写死在多个地方。** 现在由启动器生成一份独立的 `rcon.generated.cfg`，服务端和工具读同一个值，避免改了一处忘了另一处。

**不要相信「编译通过 = 功能可用」。** 空服测试只能证明服务端字段对，客户端能不能看到是另一回事 —— 发光、HUD、菜单渲染都得真人进服验收。

## 源码

仓库：<https://github.com/Hoshino486/ZePractice>

代码是 CounterStrikeSharp 插件，`src/` 下按功能拆成了服务层和逻辑层，`tools/` 是启动、预检、更新和回滚脚本，`docs/` 里是按版本归档的改动记录。

仓库**不含**游戏资源、地图 VPK 或工坊模型 —— 那些单独发在 Steam 创意工坊。地图数据来自 `Hoshino486/cs2` 的公开配置，版权仍归原作者。
