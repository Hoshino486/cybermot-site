BomberStudio 负责把 Unity 资源拆出来，导成 `FBX`。但这批模型到了 Blender 里，往往会遇到一堆小问题：材质没跟过来、贴图路径全丢、骨骼是 ASCII 格式读不了、顶点组乱成一团。

**BomberStudio Blender Bridge** 就是处理这些的 Blender 插件。

先说清楚它是什么：它是 **BomberStudio 导出数据的后处理插件**，不是能在 Blender 里直接解包 Unity 资源的工具。解包仍然在 BomberStudio 里做，这个插件负责把拆出来的东西整理到能用的状态。

## 一、下载与安装

从仓库 Releases 下载 **`Universal.zip`**（当前 1.2.0）：

> <https://github.com/Hoshino486/BomberStudio_Blender>

**注意：不要点 GitHub 的「Code → Download ZIP」**，那是源码包，装不上。要的是 Releases 里的 Universal 压缩包。

装之前先保存正在编辑的 `.blend`。然后按你的 Blender 版本找入口：

| Blender 版本 | 安装入口 | 面板位置 |
|---|---|---|
| **2.79** | 文件 → 用户设置 → 插件 → 从文件安装 | 3D 视图左侧 **T** 工具架 |
| **2.80 ～ 4.1** | 编辑 → 首选项 → 插件 → 安装 | 3D 视图右侧 **N** 侧栏 |
| **4.2 及以上** | 编辑 → 首选项 → 插件（获取扩展）→ 右上角菜单 → **从磁盘安装** | 3D 视图右侧 **N** 侧栏 |

安装完搜索 **BomberStudio Blender Bridge** 并勾选启用，回到 3D 视图按 `N`（2.79 按 `T`），能看到 **BomberStudio** 面板就说明装好了。

面板里应该至少有这几个按钮：**导入 BomberStudio 模型**、**导入 BomberStudio PC2 物理缓存**、**导出 FBX**。

## 二、第一次打开：先设置工作目录

展开「**BomberStudio · 快速访问**」→「**设置与诊断**」，把四个目录指到本机能写的地方：

- 临时目录
- 日志目录
- 备份目录
- 图集输出目录

后面所有转换、图集、日志都往这里写。默认位置在 Blender 用户配置目录下，能用，但建议单独放一个工作文件夹，方便找日志。

## 三、从 BomberStudio 导出

这一步决定了后面顺不顺利：**导出时保持目录结构，不要把模型和贴图拆散到不相关的地方**。

理想情况是这样：

```text
角色A/
├── 角色A.fbx
├── 角色A.fbx.genshin.json   ← 材质旁文件，有就一起保留
├── Materials/
└── Body_Diffuse.png
```

插件会读取导出器生成的旁文件（`.genshin.json`、`.starrail.json`、`.hi3.json`、`.zzz.json` 等），用它恢复贴图槽位和材质参数。**不是每个模型都有**，有就留着，别手贱删掉。

## 四、导入与检查

点「**导入 BomberStudio 模型**」，选 FBX。

第一次导入时：

- **比例保持 `1`**，先别动
- **不要急着开「自动骨骼方向」**，方向不对时再回来改
- ASCII FBX 会自动转成二进制缓存再导入，原文件不会被覆盖或移动

导入后先看大纲：网格、骨架、形态键、动画，缺哪一项说明导出或导入有问题。

然后切材质预览看贴图。**有缺图或材质发灰，先去看临时目录里的 `last-import.json` 和 `bomberstudio.log`**，日志里会写清楚是哪张图没找到、哪个 UV 层对不上。

> 只有走插件的导入入口才会自动转换 ASCII FBX。Blender 自带的「文件 → 导入 → FBX」不会调用本插件，那条路只能喂二进制 FBX。

## 五、整理模型与打图集

面板上的整理按钮不少，但**不要依次全点一遍**。位置归零、删除顶点组、分割模型是不同目的的操作，未必适合当前模型。

操作前先存一次 `.blend`。只选要处理的网格再点按钮，**最后选中的物体算活动物体**，很多操作以它为准。

常用的几个：

- **位置 / 旋转归零**：模型不在原点时用
- **删除孤立点**：清理没用的散点
- **相同材质合并**：材质数量爆炸时用
- **网格连接 / 分割**：按部件拆合

### 打图集

流程是固定的四步：

1. **生成材质列表**
2. **勾选要打包的材质**
3. 设置尺寸、间距、是否扩展边缘、输出目录
4. **合并贴图**

默认会创建图集副本并把原模型隐藏，确认没问题再导出。支持打包成 PNG 或 TGA，也能输出 **PBR 图集**的五个通道：Base Color、Roughness、Metallic、Normal、Emission。

## 六、角色工具

做角色的时候还会用到：

- **合并骨架**、**附加网格**：把多段模型并成一个
- **身高缩放**：按目标身高统一
- **顶点组整理**：清理、排序、补号、合并同前缀、按位置匹配改名
- **口型生成**：从 AA / OH / CH 三个形态键生成 15 个 `vrc.v_*` 口型
- **眼球辅助**：创建眼骨、预览、复位

注意这些是 Blender 端的整理辅助，**不是人体自动绑定**，VRChat SDK 该配的还是得配。

## 七、物理缓存（PC2）

如果模型带了头发、裙摆这类物理，BomberStudio 可以导出 **NoWind PC2** 缓存。插件里的「导入 BomberStudio PC2 物理缓存」会校验文件、顶点数、帧数和 SHA256，对不上会直接报错 —— 这比导进去发现穿模再回头查省事得多。

## 八、导出 FBX

最后一步。在设置里确认：

- 是否导出**动画**
- 是否导出**全部 Action / NLA**
- 是否**嵌入贴图**（发给别人时建议嵌入）

**需要蒙皮的话，骨架和对应网格要一起选中**，只选网格导出去是没有骨骼的。

还有一个细节：FBX 导入的默认帧偏移是 `1`。如果你要拿 Blender 自己导出的原帧数做对比，把它改成 `0`。

## 九、支持的版本

Windows x64 实测过的版本：

`2.79b`、`3.2.2`、`4.0.2`、`4.1.1`、`4.5.5 LTS`、`5.2.2 LTS`

2.79 ～ 5.2 之间的其他版本属于兼容设计但没逐版验证；macOS 和 Linux 没测过。

## 十、常见问题

**提示 ASCII FBX 不受支持**
确认插件是 1.0.1 以上、装完重启过 Blender，并且用的是「BomberStudio → 导入 BomberStudio 模型」，不是 Blender 自带的 FBX 菜单。

**装完找不到面板**
先确认当前区域是 3D 视图（在文本编辑器里按 N 当然没有）。如果旧的 Legacy 版和新的 Extension 版同时存在，停用多余的那个再重启。

**贴图丢失、模型发紫或全透明**
先确认导出目录里真的有图片和材质旁文件。然后把「贴图目录」指对，读一次图，再用路径修复。数据 Alpha 导致透明时，勾「忽略基础色 Alpha」。

**文件存在哪？会不会上传模型？**
路径由「设置与诊断」决定。**所有处理都在本地完成，不上传模型**；唯一的联网行为是你手动点「检查版本更新」时去查 GitHub Release。
